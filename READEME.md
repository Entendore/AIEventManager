# AIEventManager

**AIEventManager** is a full-stack AI agent demo implemented in a **single Python file**. It showcases backend APIs, a dynamic frontend (HTML + JavaScript + CSS), ML-powered recommendations, and simple agent orchestration—all runnable locally without additional frameworks or Docker.

---

## Features

- **Backend:** Flask API with SQLite for events and users
- **Frontend:** Pure HTML + JavaScript + CSS interface served by Flask
- **ML:** Randomized event recommendation system
- **Agents:** Console-based agent simulation printing periodic recommendations
- **Single-File:** Everything runs from `smart_event_manager.py`
